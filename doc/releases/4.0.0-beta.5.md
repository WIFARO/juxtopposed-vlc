Windows x86_64 portable build, macOS Intel and Apple Silicon app bundles, and Linux x86_64 portable archive
Git tag: `4.0.0-beta.5`

**Full Changelog**: https://github.com/dsojevic/juxtopposed-vlc/compare/4.0.0-beta.4...4.0.0-beta.5

This beta continues adapting [Juxtopposed](https://www.juxtopposed.com/)'s VLC design for the native player.

**Update notifications:**
- Release notifications can show the published product name and an optional short announcement above the full release notes.
- Update checks support explicit release generations before comparing version numbers, while preserving normal semantic version ordering within each generation.
- Releases can describe their package filename prefix. Checks still require an uploaded package for the current platform and architecture, with release and download URLs belonging to this fork's repository.
- Existing releases without metadata remain supported. Stable builds continue to exclude prereleases.
- Release assembly validates the metadata and includes it in the release notes and `UPDATE_METADATA.json`.

**Use:**
- Close earlier VLC windows before starting this build. Keep each download's complete contents together.
- Windows 10 (1809 or later) / Windows 11, x64: extract `vlc-juxtopposed-4.0.0-beta.5-win64.zip`, then open `vlc-win64/vlc.exe`. To retain portable settings, copy the previous build's `portable` folder while VLC is closed.
- macOS: choose `macos-arm64` for Apple Silicon or `macos-x86_64` for Intel. Extract the ZIP and move `VLC Juxtopposed.app` into a folder of your choice. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it.
- Linux: extract `vlc-juxtopposed-4.0.0-beta.5-linux-x86_64.tar.gz`, then run `AppDir/AppRun`. Keep the complete `AppDir` folder together. The build targets glibc 2.35 or later (Ubuntu 22.04 or equivalent) and does not require FUSE.
- Update notifications open the matching release page. Downloading and replacing the application remains manual.
- Verify downloads against `SHA256SUMS.txt` if desired. Build metadata identifies the exact source commit for each asset.

**Current limits:**
- These are experimental builds; interface and settings work continues.
- Windows executables have no trusted publisher signature. Mac apps are ad-hoc signed without a Developer ID signature or Apple notarization. Operating systems may warn or block the first launch.
- Mac downloads are separate native builds; choose the correct architecture. Build metadata records the minimum supported macOS version.
- Linux still uses the host's graphics drivers and desktop/audio services; behavior can vary between distributions.
- The media library database must be on a local drive; media folders may be on a network share.
